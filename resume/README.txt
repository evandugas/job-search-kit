Put your resume files in this folder: PDF, DOCX, TXT or MD.

- You can add several versions (for example one aimed at data roles and one at lab roles). Claude
  scores every posting against all of them and starts each tailored resume from the closest one.
  When versions disagree on a fact, the newest file wins.
- Optional: copy corrections.example.txt to corrections.txt. It overrides every resume file (fixed
  dates, a corrected GPA, skills you have that no resume mentions, things never to claim).
- Everything in this folder except these two help files is gitignored, so your resume stays private.
